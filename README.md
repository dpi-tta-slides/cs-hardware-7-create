# CS Hardware Day 7 - Create

In this lesson, participants bring together everything learned throughout the week to create a complete hardware project. Building on electricity, transistors, timing circuits, integrated circuits, microcontrollers, and soldering, participants explore how engineers transform ideas into real products. Participants examine famous prototypes and handmade engineering mockups to see how successful products often begin as rough experiments. The lesson culminates in a capstone build session where participants design, build, debug, document, and present an original hardware project.

[Slides](https://dpi-tta-slides.github.io/cs-hardware-7-create/)

## Learning Objectives

By the end of this lesson, participants will be able to:

- Explain the role of prototyping in engineering
- Identify characteristics of successful hardware prototypes
- Describe the iterative engineering design process
- Build a simple electronic craft project
- Document a hardware project
- Debug and improve a prototype
- Present a completed project
- Connect all seven days of learning into a complete hardware system
